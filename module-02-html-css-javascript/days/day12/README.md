# Habesha Eatery Mini-Site

Habesha Eatery is a fictional Ethiopian restaurant located in Bole, Addis Ababa.

# Pages

- `index.html` — Reservation page with reservation form, menu table, image, and map.
- `contact.html` — Contact page with contact form and opening-hours table.
- `exercises.html` — Day 12 exercises covering forms, tables, media, and accessibility.

# How to Open

1. Open the `day12` folder.
2. Open `index.html` in a web browser.
3. Use the navigation links to move between the Reservations and Contact pages.

## Accessibility Features

- Semantic HTML landmarks.
- One `h1` on each page.
- Labels connected to all form controls.
- Required form validation.
- Email and telephone input validation.
- Meaningful image `alt` text.
- Tables with captions.
- Table headers using `scope="col"`.
- `thead` and `tbody` used correctly.
- Accessible iframe titles.
- Keyboard-accessible buttons and navigation links.
- Unique page titles.
- Meta descriptions.
- Charset and viewport meta tags.

## Validation

The pages should be checked with the W3C HTML Validator and corrected until there are zero errors.
