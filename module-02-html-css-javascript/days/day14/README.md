# Day 14 CSS Layout — Exercises

Exercises 1–5 are combined into one submission.

1. Flexbox navbar: logo left, three links and a button right.
2. Four cards using `flex: 1`, `flex-wrap`, and `gap`.
3. Gallery using `repeat(auto-fit, minmax(200px, 1fr))`.
4. Full page using `grid-template-areas`, collapsing below 700px.
5. Product card using relative + absolute positioning for an ETB Sale badge.

Concepts: Flexbox, Grid, fr, repeat(), minmax(), auto-fit, grid-template-areas,
grid-area, flex-wrap, gap, relative, absolute, and media queries.
