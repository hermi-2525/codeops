# Day 13 Mini-Project — Business Profile Card

## Files
- `index.html` — the self-contained business profile page.
- `styles.css` — all styling, using the CSS concepts from Day 13.

## CSS techniques used
- `:root` custom properties for colors, spacing, radius and font stack
- `var()` for reusable values
- Global `box-sizing: border-box`
- Google Fonts web font
- Box model: padding, border, border-radius and margin
- Centered card
- Typographic hierarchy using `rem`, font-weight and line-height
- HSL brand and hover colors
- `:hover` button state changing only HSL lightness
- `:focus` outline preserved for accessibility
- `::before` pseudo-element for a decorative accent
- Responsive media query
- No inline CSS and no ID used purely for styling
